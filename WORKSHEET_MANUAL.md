# EquationWright v7.3 — Worksheet & Quiz Guide

This file is the short web-friendly guide for the current v7.3 release.

For the complete documentation, use **`EquationWright_v7_3_Complete_User_Manual_with_Developer_Notes.pdf`** at the repository root. The approved copy of that same manual is also stored inside `releases/v7.3/`.

## Student quick start

1. Open the v7.3 online or offline app from `index.html`.
2. Choose **Student** mode.
3. Select a preset such as **Quick Quiz** or open an assignment/share link from your instructor.
4. Work the questions and use the built-in feedback, hints, scratch tools, and worked solutions as available.
5. Export results when you want to save or share an attempt.

## Teacher quick start

1. Open the v7.3 app in **Teacher** mode.
2. Pick a course, units/topics, question counts, and a seed.
3. Generate a worksheet or enable Quiz Mode.
4. Reuse the same compatible release + settings + seed when exact deterministic replay matters.
5. Export/share blueprints or result data as needed.
