# Approved Releases

This directory contains organized approved release bundles.

## v7.3

`v7.3/` is the authoritative approved EquationWright v7.3 package. It contains:

- online and offline application builds under `app/`
- the complete user/developer manual
- release notes and release verification material
- evidence and acceptance results
- examples
- manifests and capabilities metadata
- schemas
- the packaged modular source
- `EquationWright_v7_3_FINAL_APPROVED.zip`

The public root-level v7.3 app files and manual are intentionally kept for simple GitHub Pages URLs. CI verifies that those public files are byte-for-byte identical to the corresponding approved artifacts in this directory.

Historical package ZIPs live under `../archive/releases/`.
