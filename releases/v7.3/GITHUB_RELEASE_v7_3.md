## What v7.3 is

EquationWright is a modular deterministic mathematics assessment engine that builds into self-contained single-file browser applications. The modular source keeps generators, curriculum profiles, schemas, registry/bindings, and application modules separate for development, while the Python release builder produces the distributable online and offline HTML files.

The approved v7.3 catalog contains 81 units and 424 published generator families. Curriculum profiles can reorganize and label the same generator catalog for different course structures without redefining the underlying mathematics.

For protocol, replay, compatibility, curriculum-profile, and modular-build details, see the repository's v7.3 release notes.
