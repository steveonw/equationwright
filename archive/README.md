# Archive

This directory holds historical release packages and superseded documentation that are useful for reproducibility but should not clutter the repository root.

## Layout

- `releases/v6.11/` through `releases/v6.17/` — historical ZIP packages.
- `releases/v7.0/` — v7.0 handoff and release manifest.
- `releases/v7.1/` — v7.1 release manifest and scratchpad release artifact.
- `docs/` — superseded or duplicate documentation retained for reference.

Older versioned HTML application files remain at the repository root on purpose so previously shared GitHub Pages assessment URLs can continue to resolve.

The current approved release is under `../releases/v7.3/`.
