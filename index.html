📚 What's Included

Math Worksheet Builder v7.3 is a single-file math practice system covering the full 18-course NVCC mathematics catalog. It generates worksheets and interactive quizzes from 424 deterministic problem generators across 81 units.

Key Features:

  • No accounts, no server required — the entire system is self-contained
  • Seeded generation — same seed produces identical quizzes forever (on that version)
  • Smart hints & trap answers — wrong answers encode specific common mistakes
  • Worked solutions — view step-by-step solutions for every question
  • Results tracking — export as CSV/JSON with labeled mistake patterns
  • Independent audits — 10,752 verified records across all courses
  • Enhanced Protocol Support — v7.3 adds curriculum profiles and advanced archival replay capabilities

🎯 Supported Courses

18 NVCC Mathematics Courses: Precalculus (CA, TRIG, PC) • Calculus (C1, C2, C3) • Applied Calculus (AC1, AC2) • Linear Algebra (LA) • Differential Equations (DE, D289) • Statistics (S155, S245, ST2, P283) • Discrete Math (DM) • Quantitative Reasoning (QR) • Health Professions (HP)

❓ Frequently Asked Questions

Which edition should I use?
Use Online if you have internet and want optional cloud features (AI tutor, cloud results). Use Offline if you need to work without internet or prefer a self-contained solution.
What's new in v7.3?
v7.3 introduces curriculum profile support, advanced archival replay capabilities, and enhanced protocol tooling for research and institutional use. See the v7.3 Release Notes for details.
Can I switch between editions?
Yes! Results are stored locally in your browser's storage. You can export results from one edition and import them into the other.
Does my data sync anywhere?
No. All data stays on your device unless you explicitly export it or use the Class tools to submit to a teacher's storage. No analytics, no tracking, no accounts.
How do I use this on my phone?
Open the HTML file in your browser. On iOS/Android, use the browser menu → "Add to Home Screen" to create an app-like shortcut. The interface is fully responsive and touch-friendly.
What's the math engine? Is it audited?
All math is generated and graded deterministically by the app's 424 problem generators. Independent audits verified 10,752 answers with zero mismatches. See AUDIT_REPORT.md for details.
